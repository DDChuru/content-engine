## MEMORY HOOKS: slow, spelled out, one link at a time (Durai, 27 Sep — from 6.1.1-2 "pure as gold")
Durai liked the mnemonic *pure as gold* (purines = A, G) and wants more of this pattern wherever an honest one
exists — but it went by too fast and he had to rewatch. Rule for every memory hook:
- **Say each link explicitly**, one at a time: *"Pure — purine. As — adenine. Gold — guanine."* Never just the phrase.
- **Highlight each link as it is spoken**: the hook word and its target light together (e.g. **PUR**e ↔ purine label,
  **A**s ↔ A plate, **G**old ↔ G plate), then a **2 s hold** on the completed mapping before moving on.
- Tempo: the slow teaching tempo (PACING); budget ~8–12 s per hook beyond the sentence it supports.
- The hook is never the exam answer: the creditworthy sentence follows immediately (as now).
- Storyboard authors: look for an honest hook for any list students must recall (bases, stages, organelles);
  don't force one. Checkers: flag a hook said only as a phrase, or one that passes in under ~6 s.
