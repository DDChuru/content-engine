## 2. Quotation, interpretation and evidence rules

**VERBATIM:** only the separately saved PDF and raw text are source reproductions. No Cambridge prose in this benchmark is presented as a quotation. Numeric references preserve Cambridge's topic, subtopic and outcome numbering; `C 4.1.4` means Cambridge subtopic 4.1, outcome 4. It is a separate namespace from archive leaf `AL 4.1.4`.

**PARAPHRASE / ANALYST JUDGMENT:** all narrative, shorthand navigation labels, mappings, match assessments and gap/extension judgments in this document. The numbered tree below is a reference index, **not a paraphrase standing in for the full outcome text**. Source-page links are supplied for every outcome; the PDF retains qualifications, lists, command verbs and restrictions that this index intentionally does not restate.

The user-supplied archive is the evidence for the note comparisons. Its first complete-tree entry for each AL ID is used, not repeated entries elsewhere in the file. **D** = description supports the central demand. **P** = candidate match with a specific unresolved requirement, listed in section 5. Neither means the complete original note has been checked against every clause. There is no verified full-note coverage percentage. An unmentioned detail is an evidence gap, not proof of absence from SaveMyExams.

All 124 AS note contents duplicate AL content. AS aliases in the reverse index are joined by archived content ID, including the two Water leaves whose position IDs swap. This does not determine Cambridge's stage assignments. [Archive counting and numbering rules](/home/durai/sme-9700-archive/SAVEMYEXAMS-9700-BIOLOGY.md:5); [discovery metadata](audit/plan.json).

Every outcome has a **gate owner file**. **E** means at least one existing, cited criterion supports part of that outcome; the linked `Gxx:rN` locates numbered data row N under the gate file's checkable-criteria table. **No E** means no direct matching row was assigned under this conservative rule. File existence alone does not count as evidence. E does not certify a complete rubric, the entire outcome, or a newly validated mark scheme. These files are sampled 2020–2024 evidence, with proposed learning checks; they expressly follow the notes' section numbering and do not establish current-syllabus alignment by themselves. [Gate basis](/home/durai/sme-9700-archive/GATE-CRITERIA-9700-01-CELL-STRUCTURE.md:3).

Calibration confidence is inherited from the existing section-level calibration, **not newly estimated per outcome**. It measures confidence in the description-based depth ceiling. It is independent of D/P and gate E. Every outcome links its section, including provisional DO-NOT-ADD advice. No section has High confidence. [Calibration limits](/home/durai/sme-9700-archive/COMPLEXITY-CALIBRATION-9700-BIOLOGY.md:5).

Markdown archive files have no source pagination: their citations use exact file lines or named sections. PDF citations use page numbers. This avoids inventing page numbers for unpaginated evidence.
