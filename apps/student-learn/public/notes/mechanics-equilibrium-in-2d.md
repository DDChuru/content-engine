# Equilibrium in 2D

**Cambridge 9709 Mechanics · M4.1 Forces and equilibrium**

A particle is in equilibrium when the vector sum of all the forces acting on it is zero. In two dimensions, check two perpendicular directions separately. Here we use horizontal and vertical directions.

By the end you can:

- Check equilibrium in two directions.
- Use two balances to find unknown forces.
- Explain why balancing one direction is not enough.

## Two balances, both required

Taking right and up as positive:

\[
F_{\text{right}}-F_{\text{left}}=0,
\qquad
F_{\text{up}}-F_{\text{down}}=0.
\]

Each symbol above represents the **total** force in that direction. There can be more than one force on either side.

Equal horizontal pulls cancel each other. But if the upward pull is greater than the downward pull, a vertical resultant remains, so the particle is **not** in equilibrium.

The vertical pair can be stronger than the horizontal pair. Equilibrium requires equal opposite totals along each direction; the horizontal total does not have to equal the vertical total.

## Worked example: find Q

A small object is modelled as a particle in equilibrium. Five forces act:

| Direction | Forces |
|---|---|
| Left | \(P\text{ N}\) and \(20\text{ N}\) |
| Right | \(32\text{ N}\) |
| Up | \(2P\text{ N}\) |
| Down | \(Q\text{ N}\) |

Find \(Q\). All quantities label forces in newtons; there is no mass to convert. The same \(P\) appears in the leftward and upward force labels.

**Pause:** Which direction lets you find \(P\) first?

### 1. Horizontal balance

Only \(P\) is unknown horizontally, so start there. Taking right as positive:

\[
F_{\text{right}}-F_{\text{left}}=0
\]

\[
32-(P+20)=0.
\]

Both leftward pulls belong inside the brackets. Rearrange:

\[
P+20=32
\]

\[
P=32-20=12.
\]

The force labelled \(P\text{ N}\) is therefore **12 N to the left**.

### 2. Vertical balance

The horizontal forces have no vertical component. Taking up as positive:

\[
F_{\text{up}}-F_{\text{down}}=0
\]

\[
2P-Q=0 \quad\Longrightarrow\quad Q=2P.
\]

The same \(P\) appears in both directions, so substitute the value just found:

\[
Q=2\times12=24.
\]

The unknown downward force is **24 N**.

### 3. Check the original diagram

- Leftward: \(12+20=32\text{ N}\), equal to the 32 N rightward force.
- Upward: \(2\times12=24\text{ N}\), equal to the 24 N downward force.

Both directional resultants are zero, as required.

## Check your understanding

The horizontal forces stay unchanged, but only the downward pull becomes larger. Is the particle still in equilibrium?

**Answer:** No. Horizontal balance remains, but there is now a resultant downward. Both perpendicular directions must balance.

## Remember

Draw and label every force first. Write the balance in symbols before substituting. Use the direction with fewer unknowns first, then carry the result into the other balance. Return the answers to the original diagram and check both directions.
